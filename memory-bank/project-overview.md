# Project Overview — InvestorPro

Личное iOS-приложение для учёта инвестиций. Оборачивает и расширяет существующий
Python Telegram-бот (исходный прототип, удалён из репо) в нативное приложение SwiftUI.

## Владелец
Влад. Full-stack разработчик. На код не смотрит детально — важны концепция, UX, UI.
Запускать приложение, давать скриншоты, получать аппрув по UI/UX, продолжать.

## Целевое устройство
iPhone 13, локальная установка (sideload) через личный Apple ID (Tim Владислав).
Без App Store, без своего сервера. Бесплатная подпись → сборка живёт ~7 дней.

## Стек
SwiftUI, Xcode 26, iOS 17+. Только системные фреймворки: URLSession, CryptoKit,
SwiftData, Swift Charts. Сторонних SDK нет.

## Главные фичи
1. Настройки: добавление аккаунтов по API-токену (T-Invest x N, Bybit). Токены → Keychain.
2. Главная: donut активов + сумма + разбивка % + плитки (Аналитика/Графики/История/Заметки).
3. Аналитика: 4 среза (Активы/Компании/Отрасли/Валюта), donut + легенда, 1:1 с Т-Банком.
4. Графики: стоимость портфеля (Месяц/Полгода/Год, колонки⇄кривая) + статистика движения.
5. История сделок (операции по API).
6. Заметки + импорт/экспорт Notion.
7. Темы light/dark/system, RUB/USD toggle, авто/ручное обновление.

## Данные
- T-Invest REST: getAccounts → getPortfolio → getInstrumentBy(figi). PnL=(cur-avg)/avg.
- Bybit v5 REST: getWalletBalance(UNIFIED). HMAC.
- Курс USD/RUB: ЦБ РФ XML.
- История стоимости: снимки локально (точно) + реконструкция прошлого из операций+свечей (приблизительно).

## Референсы
Скриншоты экрана «Аналитика» Т-Банка (сегменты + donut + легенда) и «Стоимость
портфеля» (бар-чарт + период + статистика). Повторяем 1:1 в обеих темах.
