# Decisions Log

- **iOS, не кросс-платформа**: нативный SwiftUI, лучший UX, Swift Charts для donut/графиков.
- **Без сервера**: всё локально на телефоне. Запросы к API напрямую с устройства.
- **Подпись бесплатным Apple ID**: сборка живёт ~7 дней. Упор на refresh при открытии + кнопка.
  Архитектура держит BGAppRefreshTask для будущего платного аккаунта.
- **История стоимости**: снимки локально (точно) + реконструкция прошлого из операций+свечей
  (приблизительно, помечается). API не отдают готовый ряд стоимости портфеля.
- **Базовая валюта**: RUB + USD переключатель, пересчёт по курсу ЦБ.
- **Тема**: light / dark / system, переключатель в настройках.
- **Графики**: тоггл колонки ⇄ кривая; период Месяц/Полгода/Год.
- **REST вместо SDK**: T-Invest gRPC SDK (`t_tech.invest`) и `pybit` не имеют Swift-аналогов →
  обращаемся к REST-зеркалам напрямую через URLSession. Меньше зависимостей.
- **Метаданные инструментов кэшируются** в SwiftData (figi→имя/сектор/валюта меняются редко) —
  экономит запросы и даёт срезы Компании/Отрасли/Валюта.
- **Xcode-проект на synchronized groups** (Xcode 16+): файлы подхватываются с диска,
  не нужно править project.pbxproj при добавлении .swift.
- **Заметки + Notion**: детали формата/токена уточняются на шаге 7.
- **AI-ассистент через ProxyAPI**: один ключ → много моделей (Gemini/GPT/Claude), OpenAI-совместимый
  `chat/completions` + SSE. Порт логики из репо AgentChat (VladislavEllert/AIAdventChallange).
  Ключ ProxyAPI → Keychain. Агент получает контекст портфеля (PortfolioContextBuilder) и даёт
  вердикт; редактируемый системный промпт; мультичаты; опц. запись советов в Notion.
- **Charts Y-ось**: компактные подписи (`100к/200к`) + `.padding(12)` под ось — иначе суммы
  режутся о левый край (фидбэк юзера, фикс внесён).
